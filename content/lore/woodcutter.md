# 伐木工

**伐木工**是民间对**异常湮灭实体**的称呼。人类现有的任何手段都无法直接观测它。存续实验室的理论组、生物组和预知组都在研究它。

## 发现

很长一段时间里，殖民地突然的生物灭绝和失联，都被当作各自独立的意外。航弦本来就不稳定，失联时有发生；生态系统也会崩溃。

预言家读博时，导师是物理系的[[弗里斯顿]]。她开始收集那些原因不明的事件：既不像人为，也找不到可以理解的自然原因。为此她找到了生物系的[[王桦]]。王桦是生态系统建模与生态系统不稳定性的专家，手里有大量殖民地生态突然崩溃的详细观测记录，她自己也一直在研究这些崩溃的原因。

预言家把这些记录和宇宙弦受扰动的数据放在一起看，其中包括[[失乐园]]的弦环改变，[[候渡]]约 F431 年那次没有兑现的窗口，以及另外一些殖民地的突然失联。她推测，存在一种无法被现有手段观测的实体；这些失联，连同一部分原因不明的生态崩溃，可能都和它有关。

## 规律

预言家用一系列微分几何工具分析这些事件，从中看出了一个极其复杂的数学规律：一个高维实体，似乎沿着某种特殊的轨道，穿过我们所在的三维切面。

它对不同生物的影响不一样，对智慧生物的影响似乎更大。预言家和王桦、陆合作时，对它影响高密度神经元的方式有了一些初步发现。

约 F444 年，她把这些写进了博士论文。几乎没有人相信。

## 预言

没有人亲眼见过这个实体，预言家却接连说中了。

| 地点 | 结果 |
| --- | --- |
| [[新苏瓦]] | 生态灭绝。预言家事先给出了时间和条件 |
| [[圣布里吉德]] | 失联 |
| [[201船坞]]（K2-201 / 03） | 预言家说服政府提前撤离了人员，随后这里遭遇了湮灭事件 |
| [[邦德之环]]空间站（K2-285 / 07） | 同样提前撤离，随后遭遇湮灭事件 |

她之前的理论不再被当作无稽之谈。报纸从此开始用“预言家”称呼她，人们也开始管那个看不见的东西叫“伐木工”。

## 存续空间站

连续损失两个殖民星球和两个大型空间站，联邦政府不得不重视起来。按照预言家的预测，下一次湮灭事件会在几十年之后。约 F446 年，联邦资助成立了[[存续实验室]]，在[[存续空间站]]上预测这些事件，研究如何让生物和文明存续下去。

预言家在信号塔顶上说过：

> 有些东西正在到来。它不会在乎谁是千金，谁是矿工。它不会区分地球和天鹅三号，不会区分花园世界和边疆。
