# 历史年表

联邦以**耻辱战争结束、《终战协议》签署之年为联邦纪元元年（F0）**。[[霓约克水族馆]]事件发生在 F449，千金绑架案发生在约 **F451**。未确定的事件不强配年份。

| 约 F−210 | **天蝎双影。** 天文学家第一次看见宇宙弦造成的成列双像。详见[[航弦探索史]]。 |
| 约 F−175 | **先到的星光。** 一颗超新星沿弦的像早亮了三年，航弦的捷径被发现。 |
| 约 F−150 | 测得天蝎主干在太阳外约一百二十天文单位处擦过太阳系（近日锚段）。 |
| 约 F−100 | **火星地球化工程开始。** 到千金绑架案时已持续五百五十一年。 |
| F−70 至 F−10 | **星际探索浪潮。** “渡鸦号”首次载人航行抵达比邻星。但人类还没有能让飞船生态长期自我循环的技术，船员数量有限，大多只能前往邻近星域，只建立了少数定居点，没有形成大规模的殖民潮。[[新伊甸]]有近五百人，是当时最大的据点。 |

| F−10 至 F0 | **耻辱战争。** 地球环境加速恶化，资源日益紧张，各核大国为油气、粮食和月球开采权大打出手。十年核战争中，地中海地区被核弹严重破坏，北大西洋环流被完全摧毁。直接或间接死于战争及其引发的生态危机的人数，接近地球人口的五分之一。战争期间，火星开始自治，选出了自己的执政官。 |

| F5 | 为了避免再度发生这样的灾祸，也为了共同应对战后的生态灾难，各国放弃民族国家的旧体制，在早期国际组织架构的基础上成立**联合政府**。《**人类联邦宪法**》通过；第二份联邦决议确立新纪元，以《终战协议》签署之年为联邦元年。 |
| F20 | 二十年的生态修复后，新伦敦、霓约克、东安（新东京）、上海第三重建区等超级都市重建。火星经过漫长谈判，同意以自治领的形式加入联合政府，并与地球分享了它在战争期间取得的一系列人工生态成果，这成为后来长途飞船的基础。 |
| F35 | 赤道上的启程城[[夸赫里尼（启程城）]]建成。时隔四十五年，人类再次向太空进发，第一波殖民浪潮开始。地球的生态修复将持续数个世纪，大量工业开始迁往小行星带。 |
| F38 | **航路署**成立，航弦与港口收归联合政府统一管理。 |
| F45 | [[天蝎中心]]殖民地建立，已有五万人规模，并第一次选举了自己的地方议会，而不是由航路署派遣管理人员。新伊甸认为自己在约 F−50 年就选举过领袖；天蝎中心则坚持那只是五百人的小团体推选头领，不是完整的政府选举。谁才是第一个太阳系外的民选政府，两边至今时有争执。 |
| F50 | 宗座结束了五十年的“第二阿维尼翁时期”，在教宗托马斯·孔蒂（后封圣为圣托马斯）的带领下迁往殖民地，在[[各各他]]建立新梵蒂冈。 |
| F100 | 各大殖民地陆续成立地方政府、派出议员，联合政府演变为**银河系联邦**。太空摩门教开始漫长的银心朝圣殖民，建造巨大的世代飞船，希望沿着天蝎航路尽可能靠近银心。 |

## 关于“最后一战”

“地球上的最后一战”是一句誓言，并不意味着四百五十年里没有任何战争。边疆冲突、对外摩擦依旧存在，只是它们都发生在地球之外。

## 地球的恢复

四百五十年后，地球的生态在很多指标上甚至好过战前：超级都市被森林包围，郊野重新长满野生林地。但北大西洋环流没有回来——不列颠的冬天比旧时代冷得多，新伦敦依靠一张覆盖整座城市的地下供热管网取暖。海平面上升约八米，泰晤士河口被海水吞没，旧金融城沉入水下，新金融城以浮岛形式重建。详见[[地球：海平面上升八米之后]]。
