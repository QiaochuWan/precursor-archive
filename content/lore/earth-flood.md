# 地球：海平面上升八米之后

*在[疆域图](#map)里点“地球”，可以看到这颗星球现在的样子：浅青色的近岸区域是被海水吞没的旧陆地，金色圆点是重建的超级都市。*

## 发生了什么

耻辱战争是人类在地球上的最后一战。战争和战争之前的几个世纪，把温室效应推到了接近极限：

- **格陵兰冰盖大部分消融**，只在东部高地残留冰帽；南极西部的冰架也大面积崩解。全球海平面因此上升了**约八米**。
- **北大西洋经向翻转环流（AMOC）彻底停摆**。欧洲西北部失去了来自墨西哥湾的暖流，冬天漫长而寒冷，雨水一年四季都带着北海的寒意。
- **地中海地区遭到核弹的严重破坏**。罗马与梵蒂冈被废弃，宗座被迫迁往殖民地，最终在[[各各他]]建立了新梵蒂冈。

## 新的海岸线

八米听起来不多，但世界上最肥沃、人口最稠密的土地，恰恰都在海拔八米以下。

| 地区 | 今天的样子 |
|---|---|
| 荷兰、比利时北部与德国北海沿岸 | 大部分沦为浅海 |
| 泰晤士河口 | 被海水吞没，伦敦旧金融城沉入水下 |
| 恒河—布拉马普特拉三角洲 | 孟加拉的平原大部分成为海湾 |
| 长江三角洲与苏北平原 | 部分淹没，上海经历了三次重建 |
| 湄公河三角洲 | 几乎全部被淹没 |
| 尼罗河三角洲 | 北半部沦为浅海，亚历山大港旧城沉入水下 |
| 密西西比河口、佛罗里达南部 | 新奥尔良、大沼泽地与迈阿密一带成为浅海 |
| 亚马孙河口 | 河口的岛屿与低地被淹没 |

## 超级都市

重建的城市都向高处、向海上长；最年轻的那一座，干脆建在了赤道高原上：

- **新伦敦**：泰晤士河口沦陷后，新金融城以浮岛形式重建；整座城市靠一张地下供热管网过冬，一千四百座雨水花园和两百公里的地下蓄水廊道让它学会了和雨一起生活。《千金绑架案》的主舞台——Golden Days 游乐园、第三银行、联邦大学、银币剧院，南端旧港区还立着一座停工在六十四层的信号塔。郊外是哈灵顿庄园和重新长满野生林地的森林。
- **霓约克**（新纽约）：曼哈顿下城、布鲁克林沿岸与新泽西草甸成为浅海，城市在高地和人工岛之间重新长了出来。哥伦比亚大学在这里；[[霓约克水族馆]]里养着地球上最后一只大王乌贼。
- **东安（新东京）**：关东低地东部被淹没后，城市向西侧的台地与丘陵重建。
- **上海第三重建区**：建在人工高地和环形海堤之上，东亚最大的海上都市。
- **[[夸赫里尼（启程城）]]**：唯一一座不是“重建”的超级都市。战后在赤道上的肯尼亚高原从零建起，人类走向星海的出发大厅。

## 漫长的恢复

四百五十年后，地球的生态在很多指标上甚至好过战前：重工业迁往小行星带，超级都市被森林包围，郊野重新长满了野生林地。格陵兰裸露的岩地上正在长出苔原。

但有些东西回不来了。北大西洋环流没有回来，被淹没的三角洲没有回来，地中海核毁伤区的修复至今没有完成。地球仍在漫长的生态恢复中——它是人类的母星，也是人类最大的一道伤疤。
