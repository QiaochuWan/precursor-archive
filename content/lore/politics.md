# 联邦政治架构

银河系联邦是**议会制**国家，实行三权分立：**议会最大，法院独立**。它像《苍穹浩瀚》里那样充满地方利益的拉扯，远方星区的委任统治有几分《战锤》的味道，宣传口径又让人想起《地狱潜兵》——但联邦的议会、法院和公民生活是真的在运转，它不是独裁国家。

耻辱战争把地球生态推到了崩溃边缘，幸存的各国政府停战重建，联邦就从这一战后秩序中形成。约四百五十年后，地球仍集中着议会、档案、司法与金融机构，航运重心却早已延伸到太阳系之外。

## 政体与任期

| 机构 | 产生方式 | 职能 |
|---|---|---|
| **联邦议会** | 各星域按人口选出议员；地外成员文明委托代理议员 | 最高权力机关，立法、批准预算与战争授权、选出秘书长 |
| **联邦政府** | 秘书长由议会多数提名并通过信任投票，再由秘书长选任委员组成内阁 | 行政、外交、航路、防务与公共服务 |
| **联邦法院** | 独立任命 | 司法终审与宪章审查；下设联邦调查中心与司法调查科 |

**八年任期。** 联邦议会一届任期八年，议会产生的政府随之任期八年，秘书长可以连任。制宪者面对的难题是：边疆议员的一次请示与答复，就可能耗去数年。如果地球上的执政班子更换得太快，选区收到第一封回信时，给出承诺的人可能已经卸任。八年任期让中央政府在辽阔的联邦里保持相对稳定，也给地方留下就同一项政策交涉、等到答复并付诸实施的时间。任期内，议会可以用**建设性不信任案**更换政府，但必须同时提出继任人选。

**秘书长与内阁。** 联邦的最高行政长官称为**秘书长**，内阁成员称为**委员**。秘书长来自议会多数；无一党单独过半时，由联合多数提出人选。议长和秘书长是两个人：议长主持议事与质询，保持中立。联邦最高秘书处负责内阁协调和公文传递。

**系外出生配额。** 联邦宪法要求，全体委员中至少有 30% 出生于太阳系外。比例按委员的出生地计算，秘书长本人不计入。

## 议会

**席位。** 每个自治星域取得基本代表席，另按经过核验的人口增加席位。

**全权委任。** 因为跨星系通讯受航路制约，远方选区的议员大多接受**全权委任**，在地球独自谈判和表决。委任书写明任期、谈判权限、替补人选和有限的延续期；议员定期把投票日志和财产申报寄回选区。撤销委任的通知要经议会认证才生效；委任过期而选区的确认迟迟未到，席位会降为“看守席位”。

**常设委员会。** 财政、航路、防务、司法、科学与成员文明等常设委员会审议专项事务，并就政府的执行情况提出质询。

**异星代理议员。** 少数地外文明已经加入联邦。地球的生存条件不适合一些成员亲自赴会，它们便委托人类出任**异星代理议员**。有的代理人终其一生都没见过自己代理的文明。议会俚语把他们叫作“后排议员”，这只是说他们的处境，与表决权重无关。为了避免代理人曲解委托，重要委任书须附上受托文明自己的陈述，供议会核对。

## 司法与调查

| 机关 | 职权 |
|---|---|
| 地方法院与上诉法院 | 普通争议就近审理，涉及生命保障的案件可以先获临时救济；跨区重大案件逐级上诉 |
| 最高法院 | 终审，下设宪章审查庭 |
| **联邦调查中心** | 隶属联邦法院，侦查跨区犯罪与公职腐败，有权调查议员和官员；《存续法案》下的存续空间站监督项目也由它执行，[[马丁·米勒]]与[[道格拉斯]]在这里任职 |
| **司法调查科** | 独立公诉机构，决定是否起诉，可以签发紧急搜查令、调阅通信元数据（不含内容）；《千金绑架案》中的诺兰检察官属于这里 |
| 法务委员（政府） | 主管法律草案、监所和司法行政；个案判决只能由法院作出 |

调查取证必须留档，并按权限申请司法授权。

## 防务与紧急状态

议会批准战争授权和军费；秘书长与防务委员承担文官统军的行政责任，军事指挥机构执行命令。联邦设远航舰队、地方防卫部队和探索舰队。月球防卫军负责地月安全，它对存续空间站的保护权限以书面任务令为准。

紧急封锁必须记录理由、签发人和终止条件。在地月地区，军方须在二十四小时内向值班法院及独立监督官说明依据；在边疆，由当地机关及时复核。任何紧急数据调用都会留下可以被复核的记录。《联邦深空公约》规定了遇险时的人道救援义务。

## 公共财政

中央预算与地方预算分立。议会批准国家项目，内阁执行授权，财务委员负责拨款和账目。边疆居民的养老金和事故赔偿，可由地方准备金先行支付，中央随后清算。

[[星际开拓计划与天鹅一号事故|星际开拓计划]]约占联邦中央年度支出的一成，覆盖科研、航路、船坞、殖民配套和防务采购，存续实验室的拨款只是其中一项。第三银行参与存续项目融资，并托管教会资产与圣彼得之钥。

## 地方自治与航路治理

行政层级依次为**联邦、象限、星区、星域、恒星系、殖民地**，详见[[疆域、象限与行政区划]]。

| 层级 | 日常职能 |
|---|---|
| 联邦与象限 | 联邦处理共同宪章、外交、总预算和跨区防务；四个象限用于大尺度航路与远征协调 |
| 星区与星域 | 星区协调跨星域交通、上诉和军政事务；星域负责区域财政、安全和公共服务。**星域总督**是辖内最高综合行政长官，由秘书长提名、星域议会同意，再经联邦确认 |
| 恒星系与殖民地 | 系务部门协调港口和轨道交通；**殖民地事务官**主持当地政务，管理治安、土地、教育和生命支持；成熟的聚居地设地方议会 |

中央统一跨区导航、共同市场规则和宪章权利；地方管理港口、地方税和生境许可；支线维护、灾害赔偿、移民保护和跨境污染由双方分担。距离越远，地方自治越强。

**政治身份。** 一个成员世界在政治上可以是核心成员地、特许自治领、普通自治地、开拓托管地或成员文明领地。“工业世界”“渔业世界”说的是当地产业；“失联”则是一种联系状态，关系到居民身份、资产托管和救援责任。

**法令的送达。** 联邦登记每一项法令在各地的送达时间，新的义务从当地公布并经过宽限期后才生效。闭航期间，地方照常换届、审判和救灾；航路恢复后，再处理授权更新、旧债清算和居民的代表资格。以[[候渡]]为例，名录把它列为“待复联”：预期的窗口落空，旧的人口登记仍在，居民的近况却无人能够证实。[[失乐园]]曾被视为人类的第三中心，联邦正准备委派总督尝试重联；这只说明了地球方面的计划，当地由谁治理仍是未知数。

## 政治中心与工业聚居地

- **地球与天蝎中心。** 地球保有战后联邦的政治中枢。[[天蝎中心]]是多条航路交汇附近最大的殖民地，与联邦最大的工业世界[[灰铁星]]同处格利泽 667 C 星系，在交通与经济上早已是事实上的第二中心；正式的政治副中心地位，是宇宙边疆党仍在争取的目标。对偏远选区来说，区域清算、保险、仲裁和船队调度设在哪里，直接决定申诉要多久才能送到、救援船何时能启航。
- **环地球贫困带。** 地球把大量工业转移到小行星带和木星、土星一带的聚居地，详见[[内太阳系]]。
- **火星自治领。** 拥有自己的议会、执政首长和自治法院，详见[[火星自治领]]。
- **各各他与基洛伯。** 宗座所在的各各他由公民政府治理，宗座辖区以协定保障；基洛伯的居民议会与教会分掌世俗与宗教事务，详见[[宗教：宗座、各各他与基洛伯]]。

## 政党

| 政党 | 当前地位 | 支持基础与主张 |
|---|---|---|
| **联邦共同党**（联邦党） | 长期执政，本届主导组阁；詹姆斯·沃顿与井上幸两届后支持率下滑，由拉纳辛哈逆风翻转 | 核心城市中产、中央文官和公共工程管理者；统一宪章、主干航路维护与长期公共投资 |
| **劳动与生境党**（劳动党） | 联合执政，掌财务委员席 | 矿工、船员、生态工程与公共服务雇员；事故赔偿先付、劳动保护、生命支持设施公共化 |
| **自治协约党**（协约党） | 最大反对党 | 火星自治派、星域议会与地方企业；地方保有更多财税权，限制中央接管，总督须接受问责 |
| **宇宙边疆党** | 声势上升，挑战最大反对党地位 | 党员主要来自天蝎中心；口号取自“universe last frontier”，主张人类去中心化，让天蝎中心获得正式副中心地位，并在其他星区建设更多副中心 |
| **非人类联盟** | 小党，争取参与联合执政 | 部分异星代理议员；成员文明平权、议会生境适配和智能体保障 |
| **开拓与安全党** | 小党 | 防务工业、部分军人与航路承包商；防务投资、星际拓殖和长期威胁应对 |
| 地方名单与独立议员 | 分散 | 围绕特定殖民地、教区或航运城市的拨款、港务和公共服务结盟 |

协约党关心的是一个星域能自行决定多少事务；边疆党进一步追问，整个联邦可以在哪里作决定。智能体公民不得加入任何政党，见[[智能体权利与人格登记]]。

## 拉纳辛哈内阁

故事发生时，联邦处于**拉纳辛哈内阁**第二任期的中段。秘书长[[哈里妮]]全名**哈里妮·马利蒂·拉纳辛哈**（Harini Malithi Ranasinghe），今年 65 岁，斯里兰卡裔，出生在斯里兰卡的一座生态农庄。她毕业于联邦大学，是殖民历史学博士，还考取了律师证。她所属的联邦共同党与劳动与生境党联合执政，支持率很高。

**从学者到秘书长。** 读博前后，她曾在[[努鲁·卡马乌]]殖民地做殖民历史考察，研究当地的异星文明遗迹；后来回到太阳系，在小行星带做早期殖民历史研究。那段时间她接触了大量小行星带的工人，义务为他们担任劳动法律师。她后来赢得地方选举，以小行星带选区议员的身份加入联邦共同党，在党内的地位不断提高，同劳动党的关系也一直很好。詹姆斯·沃顿内阁和井上幸内阁相继失去民心，联邦党的支持率一路下滑；她逆风翻盘，拯救了联邦党的支持率，并与政治盟友劳动党联合组阁。她与[[哈灵顿家族]]的关系很好。

**前两届内阁留下的问题。** 哈里妮上台前，前秘书长詹姆斯·沃顿（德国裔）和井上幸（日裔）先后领导了两届政府。两届内阁都偏重内太阳系核心地区和主干航路殖民地，偏远殖民地的困难逐届累积，决策在内阁更迭后仍有影响。这些长期得不到解决的问题，促成了 [[the A]] 的诞生。“环地球贫困带”也长期无人在议会代言。哈里妮当选后，偏远殖民地和太阳系工业聚居地都进入了中央政府优先考虑的范围。

詹姆斯·沃顿卸任后又在议会坐了几届，如今已辞去议员职务，却仍是名流晚宴上的常客，并一直在为儿子铺路。他的儿子[[小詹姆斯]]（小詹姆斯·沃顿）同样是联邦共同党议员，选区在西北欧，曾任开拓计划预算委员会委员。

**撤离与《存续法案》。** 约 F445 年，哈里妮的第一个任期将满，预言家的预测相继应验：伐木工湮灭导致[[新苏瓦]]与[[圣布里吉德]]失去联系，[[201船坞]]和[[邦德之环]]空间站也即将受到波及。拉纳辛哈内阁在危险到达前撤走了两座空间站的人员，这次撤离为她赢得了广泛支持，她在同年连任。次年，她借这股支持推动议会通过了[[存续法案与监督项目|《存续法案》]]，存续实验室随后依法秘密建立。解决伐木工问题，从此成为她两届政府的要务之一。
