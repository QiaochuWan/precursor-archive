# 17. 现实校核与创作边界

以下资料仅用于少量现实约束；所有政治制度与技术突破均为本稿创作建议，不是现实法律意见或对既有作品设定的复述。

- NASA，2018，*Mars Terraforming Not Possible Using Present-Day Technology*：现有研究不支持仅靠可利用的火星本地CO₂资源完成这种增压暖化。因此本稿为未来文明补入挥发物进口及更高等级工程，而非否定作者设定。https://www.nasa.gov/news-release/mars-terraforming-not-possible-using-present-day-technology/
- NASA，*Mars Facts*：当代火星没有全球磁场。本文的人工屏蔽是未来虚构方案，不把它当作已存在设施。https://science.nasa.gov/mars/facts/
- NASA，*Target Star Catalog*：τ Ceti列为距地球约11.9光年；因此建议小说统一为约12光年。https://science.nasa.gov/exoplanets/target-star-catalog/

未来若要制作可计算的航路图，应另建每一航段的长度、航时、开放窗口、通量和所属行政区，而不是从天空星座名称反推政治边界。
