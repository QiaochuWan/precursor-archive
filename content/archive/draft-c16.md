# 16. 后续增补的记录模板

后续跑团log、聊天记录和短文按下表追加，不直接覆盖旧版本：

| 字段 | 填写方法 |
|---|---|
| 条目编号 | 如POL-001、LOC-003、CHAR-AMA、EVT-105；编号稳定，名称可改 |
| 陈述 | 一条可独立判定的事实，不把推理混入同一句 |
| 来源 | 文件、章节、log日期、发言者 |
| 证据类型 | 作者明确设定／正文事件／角色陈述／传闻／新增提案 |
| 故事时间与适用地域 | 某时某地有效，不随意推广为全联邦现状 |
| 知情范围 | 玩家公开／部分角色知情／GM秘密 |
| 相关条目 | 人物、机构、法律、地点、事件链接 |
| 冲突与处理 | 并存、修订、撤销、待定；留下旧说法 |
| 确认状态 | 待作者确认／已确认／已弃用 |

疆域尺度与无人星门项目已获作者确认。下一次优先确定：①主干转入麦哲伦弦的接入机制、周期及窗口；②求知者启航、建站与回传年代；③阿明、Astrea、弗莱明的姓名与成长时间；④天鹅二号灾害与天鹅一号赔偿分别是什么事件；⑤未登记智能体的最低权利。四象限坐标框架已确认，星区与星域数量仍是建议。
