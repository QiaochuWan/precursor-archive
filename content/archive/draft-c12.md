# 12. 地理与研究机构索引

### 12.1 主要世界

| 地点 | 已有定位 | 整理说明 |
|---|---|---|
| 地球 | 母星、联邦中心、花园世界 | 议会具体所在城市尚未明确；新伦敦不自动等于首都 |
| 火星 | 自治领、工业世界、地球化工程 | 地表生态与轨道工业并存；阿明博士关联 |
| 木卫二 | 工业世界 | 陆关联；内太阳系殖民成熟不排除木星已有据点，但需区分开发程度 |
| 天蝎中心 | 格利泽667 C h，最大殖民地，花园世界 | h为虚构殖民行星，不宣称现实已确认；宿主星系采用观测约23.6光年；弗里斯顿关联 |
| 灰铁星 | G667C c，同系最大工业世界 | “最大”按产值、人口还是重工业产能待定 |
| 各各他/新各各他 | 鲸鱼座τ星c，宗教世界，新梵蒂冈所在地 | 建议星球正式名“各各他”，初期殖民地旧称“新各各他”；是否采用待定；艾迪关联 |
| 太平星 | 天仓五b，农业世界 | 与各各他同系，便于短程供应 |
| 天鹅一号 | 天鹅星区较发达殖民地 | 接收二号灾民；小说有一号赔偿账单，不等于二号灾害自动改成一号 |
| 天鹅二号 | 被自然灾害毁灭 | 灾害原因与后续责任分开；不自动改成开拓计划阴谋 |
| 天鹅三号 | Kepler-186f，渔业世界，偏远 | Astrea和船长成长地；v0.3按所检索星表更新为约579光年；原稿492光年列为旧值，真实坐标与边疆身份通过主干平均方向偏转20°协调 |
| 泰拉 | 叙述框架中的荒芜边境星球 | 未给航路坐标、殖民时间，不引入原作填空 |
| 金星 | 牦牛毛奢侈品的产地标签 | 不足以推出已完成金星地球化；可来自浮空牧场、轨道生物工业或商品地理品牌，待定 |

G667Ch、天仓五b/c及其宜居环境视作独立宇宙的虚构设定，现实星表只提供命名灵感。不要因现实某颗候选行星地位变化，强迫整个故事随之重写。
