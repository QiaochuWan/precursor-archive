# 18. v0.3观测支持的殖民地扩编提案

**资料核查日期：2026-10-28。新增28个殖民地，对应24个恒星系。名称、行政归属、产业和人工环境全部为本版创作提案，未自动升级为作者确认。**

### 18.1 科学事实与世界观假设的边界

本版以NASA Exoplanet Archive的Planetary Systems Composite Parameters表获取目标宿主星坐标与距离，并结合2026年的宜居带目录及个别目标近期观测研究。目录不是“已经发现宜居星球”的名单。恒星辐照、质量或半径只能筛选研究对象；大气、海洋、生命与适合人类呼吸均不能据此直接推定。[S1–S3]

Bohl等2026年研究给出了经验宜居带内45个目标以及更窄模型下的24个目标。不同恒星参数、宜居带边界和质量—半径假设会改变入选名单。本版不逐字照抄名单，也不把“列入目录”当作对岩质表面或液态水的独立确认。[S2]

数据表中一些RV行星的半径是质量—半径关系估计；一些凌日行星质量只有估计或上限。尤其不把LP 890-9 c的档案质量上限读成精确质量，不把RV最小质量读成真实质量。为避免混用，本版殖民名录主要展示可靠的恒星系距离与定性条件，不用拼接的参数给出伪精确宜居评分。

科学分组仅用于说明创作跨度，不是概率：

- **A：优先温带目标。** 有小型/较低最小质量行星及温带辐照依据，但仍未证实适居。
- **B：有条件纳入。** 偏暖、挥发物丰富、真实组成未知，或宜居带归类对模型敏感；封闭、地下或轨道形式更稳妥。
- **C：科研工业例外。** K2-18 b是温带亚海王星目标，不按类地宜居候选处理；保留一个围绕它的轨道殖民地，满足科研与工业叙事，而不是宣称它适合人类地表生活。

本版包含27个A/B类行星或系统殖民地提案及1个C类轨道例外。

### 18.2 新行政划分提案

这些星区只展示被本次选中目标覆盖的部分，不等于一个星区只有表中几个世界。四象限是几何测绘层，星区是交通与政治层；近邻星区可依枢纽协议协调跨象限支线，其法律辖区以成员表为准，不用天空星座边界划分三维疆域。

| 星区 | 本版涉及星域 | 经济与管理特征 |
|---|---|---|
| 母星直属星区 | 太阳、近邻 | 地球政治中心；火星自治；邻近工业维修与防务配套 |
| 天蝎星区 | 中心、近蝎、蛇渡 | 天蝎中心与灰铁星的金融—工业枢纽，周边采矿和船队服务 |
| 鲸鱼星区 | 天仓、鲸南 | 各各他与太平星传统共同体，农业、宗教、海洋工程合作 |
| 南航星区 | 近南、长春、红岸 | 生态工程、农业与畜牧，人工水产和人口扩展 |
| 北航星区 | 北仓、静原、北穹 | 储备农业、人工花园、挥发物与高压环境科研 |
| 回航星区 | 海门、双灯 | 回向及侧向航路的补给、工业栖居地和粮食储备 |
| 晨航星区 | 曙汀 | 接近稳定主体边缘的生态补给节点，承担通往周期边疆的转运 |
| 天鹅星区（既有） | 天鹅（新增星域名提案） | 稳定包络之外，一号、三号周期可达，二号灾毁 |

太阳系、天蝎中心与各各他原本没有全部定稿的星域名称，因此上述相关归属也属于建议；不能据本表倒推先前小说已经确认这些行政名称。

### 18.4 逐项依据与产业展开

以下每项的“观测基础”只涉及现实资料；“殖民提案”是虚构方案。A组不保证能完成地球化，B组也不代表必然不宜居。

**01 新亚历山大｜Proxima Cen b**

- 观测基础：受耀斑影响的近邻宜居带目标；未证实大气。参见[目标档案](https://exoplanetarchive.ipac.caltech.edu/overview/Proxima%20Cen%20b)及下列专题研究。
- 殖民提案：地下居住、轨道船坞和近邻维修。归属母星直属星区—近邻星域，主类为工业世界。

**02 新伊甸｜GJ 1002 b**

- 观测基础：近地球最小质量，宜居带内；表面未知。参见[目标档案](https://exoplanetarchive.ipac.caltech.edu/overview/GJ%201002%20b)及下列专题研究。
- 殖民提案：分区地球化、生态设计与移民接待。归属鲸鱼星区—天仓星域，主类为花园世界。

**03 GJ 1002 c / 01｜GJ 1002 c**

- 观测基础：较冷的宜居带目标；最小质量已测。参见[目标档案](https://exoplanetarchive.ipac.caltech.edu/overview/GJ%201002%20c)及下列专题研究。
- 殖民提案：聚变温室、种子库和耐寒粮食。归属鲸鱼星区—天仓星域，主类为农业世界。

**04 银帆鲱港｜GJ 1061 d**

- 观测基础：宜居带径向速度行星；未知海洋与大气。参见[目标档案](https://exoplanetarchive.ipac.caltech.edu/overview/GJ%201061%20d)及下列专题研究。
- 殖民提案：人工封闭水域、蛋白养殖与水循环设备。归属南航星区—近南星域，主类为渔业世界。

**05 新阿姆斯特丹｜GJ 273 b**

- 观测基础：近宜居带超级地球；大气未测定。参见[目标档案](https://exoplanetarchive.ipac.caltech.edu/overview/GJ%20273%20b)及下列专题研究。
- 殖民提案：受控农谷、粮食加工与生物肥料。归属北航星区—北仓星域，主类为农业世界。

**06 红背羊原｜Teegarden's Star c**

- 观测基础：冷侧宜居带、近地球最小质量；环境未知。参见[目标档案](https://exoplanetarchive.ipac.caltech.edu/overview/Teegarden%27s%20Star%20c)及下列专题研究。
- 殖民提案：供暖穹顶牧场、改造牲畜和兽医产业。归属鲸鱼星区—天仓星域，主类为畜牧世界。

**07 新大阪｜Ross 128 b**

- 观测基础：靠近或位于宜居带内缘以内；2026气候模拟仍多解。参见[目标档案](https://exoplanetarchive.ipac.caltech.edu/overview/Ross%20128%20b)及下列专题研究。
- 殖民提案：地下加工、轨道散热工业；不预设露天宜居。归属母星直属星区—近邻星域，主类为工业世界。

**08 Wolf 1061 c / 02｜Wolf 1061 c**

- 观测基础：内缘附近超级地球；热环境与大气不确定。参见[目标档案](https://exoplanetarchive.ipac.caltech.edu/overview/Wolf%201061%20c)及下列专题研究。
- 殖民提案：地下矿城、冶金；矿产富集为虚构。归属天蝎星区—近蝎星域，主类为采矿世界。

**09 GJ 682 / 03｜GJ 682 b**

- 观测基础：NASA收录；RV最小质量较大，岩质与大气未知。参见[目标档案](https://exoplanetarchive.ipac.caltech.edu/overview/GJ%20682%20b)及下列专题研究。
- 殖民提案：系统资源开采，先以轨道栖居地为主。归属天蝎星区—近蝎星域，主类为采矿世界。

**10 新比尔包｜GJ 3323 b**

- 观测基础：宜居带归类依赖恒星参数；档案辐照值偏高。参见[目标档案](https://exoplanetarchive.ipac.caltech.edu/overview/GJ%203323%20b)及下列专题研究。
- 殖民提案：地下设备制造和大气工程试验，不设自然花园。归属南航星区—近南星域，主类为工业世界。

**11 北仓｜GJ 251 c**

- 观测基础：2025确认；最小质量约3.9地球，非已证实地球同类。参见[目标档案](https://exoplanetarchive.ipac.caltech.edu/overview/GJ%20251%20c)及下列专题研究。
- 殖民提案：密闭农业综合体、储运和高压生物技术。归属北航星区—北仓星域，主类为农业世界。

**12 静海原｜Wolf 1069 b**

- 观测基础：近地球最小质量的宜居带目标；未知大气。参见[目标档案](https://exoplanetarchive.ipac.caltech.edu/overview/Wolf%201069%20b)及下列专题研究。
- 殖民提案：终端生态改造与景观世界；可居地形为虚构。归属北航星区—静原星域，主类为花园世界。

**13 阿祖尔海｜LHS 1140 b**

- 观测基础：水世界/挥发物丰富模型可行，2026大气争议未解。参见[目标档案](https://exoplanetarchive.ipac.caltech.edu/overview/LHS%201140%20b)及下列专题研究。
- 殖民提案：先设轨道水产栖居地；海洋分支保留为创作假设。归属鲸鱼星区—鲸南星域，主类为渔业世界。

**14 圣布伦丹｜TRAPPIST-1 e**

- 殖民提案：修会穹顶、朝圣医院、生态伦理与档案。归属鲸鱼星区—鲸南星域，主类为宗教世界。

- 殖民提案：供暖温室、封闭农业与种源保育。归属鲸鱼星区—鲸南星域，主类为农业世界。

**16 蓝鲸湾｜TRAPPIST-1 g**

- 殖民提案：冰下/穹顶养殖需人工水体；不宣称已发现海洋。归属鲸鱼星区—鲸南星域，主类为渔业世界。

**17 长春｜TOI-700 d**

- 殖民提案：长期改造后的花园区、大学与生态出口。归属南航星区—长春星域，主类为花园世界。

**18 新蓬迪谢里｜TOI-700 e**

- 殖民提案：主要为轨道工业栖居地与设备维修。归属回航星区—双灯星域，主类为工业世界。

**26 玄穹｜K2-18 b**

- 观测基础：温带亚海王星；DMS及海洋解读有争议，不作类地候选。参见[目标档案](https://exoplanetarchive.ipac.caltech.edu/overview/K2-18%20b)及下列专题研究。
- 殖民提案：轨道科研工业站，不在假定海洋上建开放城市。归属北航星区—北穹星域，主类为工业世界。

**27 安雅·彼得罗娃｜Kepler-1649 c**

- 观测基础：约地球大小、温带辐照；未知海洋与大气。参见[目标档案](https://exoplanetarchive.ipac.caltech.edu/overview/Kepler-1649%20c)及下列专题研究。
- 殖民提案：包络边缘的封闭水产世界与应急储备。归属晨航星区—曙汀星域，主类为渔业世界。

**28 罗斯508采掘区｜Ross 508 b**

- 观测基础：偏心轨道掠过宜居带内缘；不是稳定地球气候。参见[目标档案](https://exoplanetarchive.ipac.caltech.edu/overview/Ross%20508%20b)及下列专题研究。
- 殖民提案：地下采矿与轨道转运，资源与矿脉为虚构。归属天蝎星区—蛇渡星域，主类为采矿世界。

### 18.5 重点目标的近期研究限制

**TRAPPIST-1 e/f/g：** NASA 2026年的系统说明仍未确认这些世界具有可供人类居住的大气。e的初步JWST结果限制了一些大气模型，不能解读为已确认氮气大气或液态海洋。圣布伦丹、TRAPPIST-1 f / 01、蓝鲸湾因而使用保护性栖居与人工生态，不把其未来宗教或农业身份包装成观测结论。[S3]

**LHS 1140 b：** “水世界”是可能的组成解释，不是已拍摄到海洋。2026年8月多项JWST分析未复现此前报告的氦吸收；其中工作讨论恒星变化、仪器效应和可能的时间变化。这里引用的是预印本，结论仍需继续检验。阿祖尔海默认以轨道水产设施和环境研究为起点；若作者选择表面海洋分支，应明确是后世探测得到的新发现。[S4]

**K2-18 b：** 2026年的气候—光化学研究给出了无需DMS的亚海王星解释，不能把有关分子的争议宣称为已经发现生命。玄穹是围绕它的人工栖居地，不是一个已证实能在海上呼吸的人类城市。[S5]

**Ross 128 b：** 2026年9月的气候模拟说明，其气候对水量、大气和自转等假设高度敏感，许多情形并非湿润宜居。新大阪因此使用地下和轨道工业形式，避免继续沿用“宁静第二地球”的简单印象。[S6]

**GJ 251 c、TOI-1266 d、L 98-59 f：** 纳入了2025年以来确认或进一步研究的目标，避免只使用2024年旧宜居目录。GJ 251 c约3.9地球最小质量、TOI-1266 d约3.7地球质量尺度和L 98-59 f的RV解，并不自动证明它们有陆地。L 98-59 f的近期独立分析支持温带外行星，但仍无直接半径与可居大气确认。[S7–S9]

**TOI-700 d/e：** 同系两个小型温带目标很适合设计互补经济。2026档案已有更新参数；d作为较有利的长期生态改造目标，e作为偏暖受控农业补充。两者的城市、农田和植物都属于联邦时代的改造，不属于TESS已经观察到的景象。[S10]

### 18.6 地图坐标的修订与保留

本版实际查询NASA档案得到赤经、赤纬和距离，转换到银道坐标，再取银盘内主干平均方向为银经20°。这是明确标注的**制图方案**，而非观测发现宇宙弦或作者已经确认的航路朝向。原点仍是太阳系，+y为银北，+x与+z在盘面内正交。取常规银河局部坐标U朝银心、V朝银经90°、W朝银北：

```text
z = U cos20° + V sin20°
x = V cos20° − U sin20°
y = W
r = sqrt(x² + y²)
```

采用当前目录位置后，天鹅三号约579光年，离轴约495.9光年，位于周期性边疆极外侧，满足作者要求。若坚持z轴严格朝银心，它将达到离轴约568光年，不能同时保留“周期≤50年边疆内”的定位；本版不通过偷偷缩短恒星距离消除这个冲突。主干偏转20°保留整体朝银心的趋势。

新增24个系统的离轴距离均小于250光年；最外侧的Kepler-1649约247光年。因此本次未人为增加大量边疆殖民地，天鹅星区继续保持稀疏边疆特色。稳定支线的存在是创作安排，观测坐标不会证明某系统天然有可航行宇宙弦。

**GJ 273距离校正：** 本次NASA复合表给出约5.92pc，但其页面同时列出约263mas视差，二者不一致。SIMBAD的Gaia视差为264.1269mas，本图采用其倒数约3.786pc，即12.35光年。原始NASA记录保留在研究快照中，不直接拿不一致的19.3光年画图。[S11]

**观测选择偏差：** 新增目标聚集在太阳附近不是联邦远端没有行星，而是目前可研究的小型温带行星样本有明显距离与观测方向偏差。不能为了填满2000光年图面而把真实恒星搬到任意位置。这28个近邻提案不代表完整网络；远端新增30处见第19节。

核心原有三个系统按真实宿主位置绘制：太阳系、格利泽667 C与鲸鱼座τ。天蝎中心所在h行星、各各他和太平星沿用独立宇宙的虚构行星安排；本图不会把它们升级成现实天文学已经确认的行星。天鹅一号、二号没有真实恒星锚定，继续用标星号的虚构占位。
