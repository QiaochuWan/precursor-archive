# 4. 联邦议会与行政内阁

### 4.1 议会：一个立法机关，兼容不同来源的代表

保留单一联邦议会，不额外强加两院制。议会内部设置常设委员会：财政与公共账目、航路与殖民事务、防务、司法与公民权、科学与存续、成员文明事务。

席位采用“基本代表席＋人口调整席”。每个具备自治资格的星域获得基本代表权，额外席位参考经核验人口。星区负责汇总和选务协调。人口普查滞后时沿用上一期结果，待新资料抵达后从下一届调整，避免每天因新邮船到港而改写议会规模。

常规议员由星域内选举产生；未具备普选条件的开拓地可由临时代表大会授权，但须明确过渡条件。当地选出旅居地球的候选人、授权现有驻地代表，均可行；代表资格来源于选区，不来源于地球中央指定。

### 4.2 全权委任如何不变成永久代管

“全权”限于授权期内的议会投票、谈判和必要妥协，并不等于拥有选区财产或取消选区自治。

- 委任书列出选区、权限、政治纲领、任期及继任顺序；不能把私人购买的授权当作公职。
- 建议议会届期六年。边疆根据预计邮程提前组织更新授权；新届开幕时仍可使用尚未到期的代表凭证。
- 若换届凭证迟到，旧代表只能在预设延续期内履职；延续期由邮程等级事先确定，不能临时给自己无限续期。超期席位转为观察席，人口归属不被注销。
- 撤销委任自可靠通知被议会认证之日起生效；已经作出的善意表决不因远方尚未送达的撤销而全数作废。伪造授权和明知被撤销仍行事另行追责。
- 议员必须定期寄送表决日志、财产申报和谈判说明；选区可在当地启动调查、冻结下一期委任、追索个人不当收益。

这并不消除代表脱离选民的问题。恰恰相反，“住在地球的边疆代表”会形成特殊阶层：他们必须替遥远选民发言，却越来越熟悉首都沙龙，越来越不了解选区新一代人的生活。

### 4.3 秘书长与议长分设

【既定】最高行政领导人为秘书长，由议会多数党党首出任；秘书长选择委员构成内阁。

【建议】保留“联邦议会秘书长”的历史称谓，正式文件可简称“联邦秘书长”。另设议长主持会议、维护议事程序，使秘书长不能一边执政，一边独占对自己的质询程序。秘书长兼具国家对外代表和政府首脑职责，无须再加一位总统。

若无政党单独过半，由联合执政多数提出秘书长候选人，经信任投票就任；通常是最大执政党的党首，但不把这一惯例写成不可变的法律。议会可通过建设性不信任案，即同时确认继任人，避免边疆几年的一个邮程中首都反复失去政府。

秘书长主持政策、提名委员、协调预算和依法统辖军队；不能单方面拨款、永久宣布紧急状态或撤销法院判决。委员就任须通过议会确认；高级常任文官负责政府换届期间的行政连续性。

### 4.4 委员会内阁

| 委员职位 | 主要职责 | 容易发生的矛盾 |
|---|---|---|
| 财政委员 | 联邦预算、债务、拨款执行 | 项目承诺远大于实际现金流 |
| 航路与交通委员 | 锚点、邮运、救援、航路测绘 | 哪条支线值得继续维护 |
| 殖民与自治事务委员 | 地方宪章、总督任命、失联重接 | 开拓指标与原住居民利益 |
| 防务委员 | 文官统军、军费、军事政策 | 将军以安全理由扩大权限 |
| 科学与存续委员 | 联邦研究体系、长期风险项目 | 当前灾害与遥远灭绝风险争预算 |
| 生态与生境委员 | 重建、生命支持标准、跨区污染 | 地球景观受益与工业世界成本 |
| 法务委员 | 法律草案、监所、司法行政服务 | 想用人事和预算影响执法 |
| 外交与成员文明委员 | 外交、外星成员协定 | 统一权利与不同生理文化需求 |
| 社会与迁徙委员 | 灾民、劳工、养老金、人口流动 | 地方接纳能力与迁徙权 |

“联邦最高秘书处”作为内阁协调和公文传递机构保留，不是凌驾法院、议会和军队的神秘第四机关。
