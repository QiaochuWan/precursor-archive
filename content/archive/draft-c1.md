# 1. 首轮口径统一

| 项目 | 材料中的不同版本 | 本稿工作口径与状态 |
|---|---|---|
| 联邦疆域 | 覆盖银河系80%；掌控大半猎户座悬臂 | 【已确认修订】仅覆盖猎户座悬臂的一部分。稳定网络主体长约2000光年、最大横宽约500光年；周期性边疆扩展到离轴半径500光年。80%银河系与“大半悬臂”均不再采用 |
| 外星成员 | 少量文明；几十种物种 | 区分文明数量与物种数量，暂不定具体数字；人类占主导、已有外星成员成立 |
| 国名 | 人类联邦；银河系联邦 | 建议正式国名为“银河系联邦”，日常与叙述称“人类联邦”；国名表达政治抱负，不代表实际占领整个银河系 |
| 议员来源 | 每个星区有议员；不同星域派遣 | 星区是席位编组层，星域是常规授权与选举层；不能把两层都算作重复席位 |
| 司法结构 | 法院—法务部—调查中心；法院独立 | 法院独立，法务部属行政内阁，调查中心另受法定独立保障；三者无单一上下级链 |
| 战后300年、火星改造400年 | 起点看似冲突 | 火星改造在战争结束前约100年已启动；战时可能减速，持续时间不等于连续满负荷施工 |
| 宗座迁移 | 战争后迁往殖民地；尚无战前星际史 | 建议战争时先迁入太阳系临时宗座，星际殖民稳定后迁新各各他，避免强加战前成熟航路 |
| 星门 | 尚可能替代曲率；小说称大麦哲伦星系已建立星门 | 【已确认修订】星门尚在实验阶段；“求知者”无人前哨携测试星门，经麦哲伦弦抵达大麦哲伦的一颗白矮星。旨在探索不依赖天然航路的跨恒星航行；不保留v0.1“星门是入航设施旧称”的补丁 |
| 各各他距离 | 10光年；第八章26光年 | 若保留鲸鱼座τ星身份，建议采用约12光年；航程另列。26光年不应不加解释地继续使用 |
| 地球生态 | “依旧恢复到比大战之前还好” | 按上下文解读为“已经恢复，部分指标优于战前”；不推定所有原生物种与环流状态均已复原 |
| 星区/大区/星域 | 天鹅星区、天鹅座大区、天鹅座星域 | 工作稿用“天鹅星区”；小说口语“大区”可保留，精确行政名称待航路图确定 |

不建议把每个旧版矛盾都解释为阴谋或宣传。能通过版本修订解决的，就明确修订；只有有叙事价值的差异才保留为世界内部争议。
